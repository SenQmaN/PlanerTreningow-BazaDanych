# Planer Treningów – Baza Danych

Relacyjna baza danych dla aplikacji do planowania i monitorowania treningów,
realizowana w ramach przedmiotu **Bazy Danych**.

## Opis projektu
Baza przechowuje dane o użytkownikach, ćwiczeniach, planach treningowych,
wykonanych treningach, pomiarach ciała i celach treningowych.

## Zakres projektu
- diagram ERD,
- schemat relacyjny i normalizacja,
- skrypt tworzący bazę,
- przykładowe zapytania,
- scenariusze testowe.

## Technologie
- Microsoft SQL Server Express
- T-SQL

## Wykorzystywane narzędzia
- Microsoft SQL Server 2025 Express
- SQL Server Management Studio 18
- draw.io lub Canva
- GitHub
